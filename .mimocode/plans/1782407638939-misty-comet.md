# Plan: Sistema Completo de Notificaciones - CURIEL

## Decisiones Arquitectonicas

- **Scheduler:** n8n (no backend) - cron jobs en n8n para recordatorios y chequeos periodicos
- **Emails:** n8n webhooks - el backend crea notificacion in-app y dispara webhook a n8n para email
- **Push:** Expo Push Notifications en mobile con backend como intermediario

### GAPS IDENTIFICADOS

1. **Sin push en movil** - Mobile NO tiene ningun manejo de notificaciones
2. **Email e in-app desacoplados** - `createForUser()` solo crea in-app, NO dispara email
3. **Sin recordatorio 30 min antes** - No hay cronjob para inspecciones proximas
4. **Inspecciones vencidas incompletas** - `overdue-inspections.json` solo semanal, solo `en_proceso`, solo admin
5. **Sin preferencias de notificacion** - Usuarios no pueden elegir que recibir
6. **Modelo Notification limitado** - Sin channel, priority, category
7. **Supervisores no reciben notificaciones in-app** - Solo admin y arquitecto
8. **Tipos incompletos en frontend** - Faltan: `inspection_overdue`, `inspection_reminder`, etc.

## Fase 3: Recordatorio 30 Minutos Antes (n8n)

**Archivo a crear:**
- `n8n-workflows/reminder-30min.json`

**Workflow n8n:**
```
Schedule (cada 5 min, lun-vie 6am-8pm):
  -> HTTP Request: GET /api/v1/inspections/internal/upcoming?minutes=35
     (nuevo endpoint interno en backend)
  -> Code: filtrar inspecciones donde scheduledDate - now <= 30min
  -> Para cada inspeccion:
     -> HTTP Request: POST /api/v1/notifications/internal/reminder
        (nuevo endpoint interno que crea notificacion in-app + dispatch email)
```

**Archivos backend a crear/modificar:**
- `backend_legacy/src/routes/inspectionRoutes.js` - agregar endpoint interno `GET /inspections/internal/upcoming`
- `backend_legacy/src/services/inspectionService.js` - nuevo metodo `getUpcomingInspections(minutes)`
- `backend_legacy/src/routes/notificationRoutes.js` - agregar endpoint interno `POST /notifications/internal/reminder`

**Flujo:**
1. n8n ejecuta cada 5 minutos (lun-vie, 6am-8pm)
2. Consulta inspecciones proximas (scheduledDate entre now y now+35min)
3. Para cada una, llama al backend para crear notificacion in-app
4. El backend tambien dispara webhook a n8n para enviar email al inspector

- Para cada inspeccion vencida:
