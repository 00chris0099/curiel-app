# Plan: Rediseño completo del frontend - Mobile-first + Professional UI

## Contexto

El frontend actual tiene problemas en móvil:
- El ConnectionStatus abarca mucho con su banner de colores
- Los botones de texto son demasiado anchos en móvil
- Los módulos de ejecución se expanden inline (deberían abrir vista nueva)
- Las notificaciones no se ven bien en el bottom sheet móvil
- El ExecutionHeader tiene mucho texto horizontal
- Falta un diseño profesional y moderno

El usuario NO quiere la carpeta `mobile/` — solo trabajar con `frontend/` para ambas vistas.

## Cambios

### 1. Eliminar carpeta `mobile/`
- `rm -rf mobile/`
- No tocar nada del backend ni la configuración

### 2. ConnectionStatus → Dot indicator en móvil
**Archivo:** `frontend/src/components/ConnectionStatus.tsx`

En móvil (debajo de `sm:`):
- Solo mostrar un dot verde/rojo de 10px con tooltip
- Nada de texto, nada de banner
- El toggle online/offline se mantiene pero ultra compacto
- En desktop se mantiene el banner completo actual

```
Móvil:  🟢 (o 🔴) — solo dot
Desktop: banner completo actual
```

### 3. Navbar → Compacta en móvil
**Archivo:** `frontend/src/components/Navbar.tsx`

- Quitar el texto "Modo claro/suave" del botón de tema en móvil → solo icono
- La ConnectionStatus en el navbar se reemplaza por el dot indicator
- El botón de menú se mantiene

### 4. ExecutionHeader → Ultra compacto en móvil
**Archivo:** `frontend/src/pages/execution/ExecutionHeader.tsx`

En móvil:
- Botón volver: solo icono (sin borde extra)
- Título: una sola línea, truncado con `line-clamp-1`
- Debajo del título: status badge inline + fecha compacta
- Los botones de acción (Informe, Enviar a revisión): SOLO iconos sin texto
  - `Generar informe` → icono `file-pdf` solamente
  - `Enviar a revisión` → icono `seal-check` solamente
  - Con `tooltip` o `title` para accesibilidad

En desktop: se mantiene el layout actual pero más limpio.

### 5. ModuleGrid → Grid de iconos + vista modal
**Archivo:** `frontend/src/pages/execution/ModuleGrid.tsx`

**Móvil (default):**
- Grid de 3x2 con tarjetas cuadradas que solo muestran:
  - Icono grande centrado
  - Nombre del módulo debajo (1 línea)
  - Badge de conteo (si > 0)
- Al tocar un módulo → abre un **modal a pantalla completa** (no expand inline)
- El modal tiene: botón cerrar arriba + contenido del módulo

**Desktop:**
- Grid de 3 columnas con las tarjetas más amplias
- Al tocar un módulo → se expande inline (como ahora, pero con animación mejorada)

**Implementación del modal móvil:**
- Nuevo componente `ModuleSheet.tsx` — bottom sheet / full-screen modal en móvil
- Se cierra con botón X o swipe down
- Transición suave de slide-up

### 6. Module sheet (nuevo componente)
**Archivo:** `frontend/src/pages/execution/ModuleSheet.tsx`

Componente modal/sheet que:
- En móvil: full-screen con slide-up animation
- En desktop: no se usa (se mantiene inline)
- Header con: botón cerrar (X) + título del módulo + icono
- Body: scrollable con el contenido del módulo
- Backdrop semi-transparente

### 7. StatsBar → Compacta en móvil
**Archivo:** `frontend/src/pages/execution/ExecutionStatsBar.tsx`

En móvil:
- Solo mostrar el área total y # de observaciones críticas (si hay)
- Los demás stats se ocultan
- Mucho más compacta: una línea con iconos pequeños

### 8. Rediseño de cada módulo para móvil
Cada módulo (`ModuleEdificio`, `ModuleFotoPlano`, `ModuleAreas`, `ModuleObsMetrica`, `ModuleObservaciones`, `ModuleConsideraciones`):

- Formularios: stack vertical completo (1 columna en móvil)
- Botones: icon-only en móvil, texto+icono en desktop
- Listas: cards más compactas con menos padding
- Eliminar texto explicativo redundante en móvil (se mantiene en desktop)

### 9. NotificationDropdown → Mejorar bottom sheet
**Archivo:** `frontend/src/components/NotificationDropdown.tsx`

- Reducir padding de cada item de notificación
- Texto más compacto (una línea para título, una para mensaje)
- Mejorar el handle visual del bottom sheet
- Agregar indicador visual más claro de no-leído

### 10. Cards y input reductores de padding en móvil
**Archivo:** `frontend/src/index.css`

- `.card`: reducir padding en móvil de `p-4` a `p-3`
- `.btn`: reducir padding de `px-4 py-2.5` a `px-3 py-2` en móvil
- Nuevo utility `.btn-icon`: botón solo icono, cuadrado, sin padding extra

## Flujo móvil (nuevo)

```
Lista inspecciones
  → Tap inspección
    → InspectionDetail (compacto)
      → Tap "Ejecutar" (icono seal-check)
        → ExecutionScreen
          → Grid de 6 iconos de módulos
          → Tap módulo → Modal full-screen con contenido
          → Tap X → Vuelve al grid
          → Tap "Enviar" (icono seal-check) en header
```
